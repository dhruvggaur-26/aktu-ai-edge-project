# aktu-ai-edge-project# SentiEdge AI

## An Intelligent Framework for AI-Driven Web Text Mining

SentiEdge AI is an NLP-based system designed to collect, process, analyze, and visualize government-related textual data from official online sources.

The project focuses on multilingual textual data processing and provides a pipeline for data ingestion followed by AI-driven text analytics.

---

## Project Overview

The system collects government-related textual data from official online sources such as:

- Press Information Bureau (PIB)
- Prime Minister of India (PM India)
- News On AIR
- DD News
- MyScheme
